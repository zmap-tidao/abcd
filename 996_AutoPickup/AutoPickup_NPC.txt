[@main]
#Say
欢迎使用自动拾取功能！\ \
<开启自动拾取/@开启自动拾取>\
<关闭自动拾取/@关闭自动拾取>\
<查看当前状态/@查看状态>\

[@开启自动拾取]
#Act
; 参数1=0: 以人物为中心 | 参数2=8: 拾取范围8格 | 参数3=500: 每500毫秒拾取一次
PICKUPITEMS 0 8 500
#Say
自动拾取已开启！\ \
拾取范围：8格\
拾取间隔：500毫秒\

[@关闭自动拾取]
#Act
; 参数3设为0可关闭自动拾取
PICKUPITEMS 0 0 0
#Say
自动拾取已关闭！\

[@查看状态]
#If
; 此处可添加检测自动拾取是否开启的逻辑（如变量检测）
#Act
#Say
当前自动拾取状态请通过游戏内表现判断。\
