# 996引擎 - 自动拾取物品功能

本目录提供996引擎（传奇/传世风格）的自动拾取物品脚本及集成说明。

---

## 一、功能说明

996引擎内置 `PICKUPITEMS` 命令，无需额外插件即可实现自动拾取。

### 命令格式

```
PICKUPITEMS 参数1 参数2 参数3
```

| 参数 | 说明 | 取值 |
|------|------|------|
| 参数1 | 拾取中心 | `0`=以人物为中心，`1`=以小精灵为中心 |
| 参数2 | 拾取范围（格） | 32位引擎最大6格，64位引擎最大8格 |
| 参数3 | 拾取间隔（毫秒） | 最小值500，设为`0`可关闭自动拾取 |

### 示例

```
PICKUPITEMS 0 8 500   ; 以人物为中心，8格范围，每500ms拾取一次
PICKUPITEMS 0 0 0     ; 关闭自动拾取
```

## 二、文件说明

| 文件 | 用途 |
|------|------|
| `AutoPickup_NPC.txt` | NPC对话脚本，提供开启/关闭自动拾取选项 |
| `Login_AutoPickup.txt` | 登录时自动开启拾取的示例 |
| `QFunction_PickupFilter.txt` | 拾取前过滤/逻辑的示例（可选） |

---

## 三、如何添加

### 方式一：通过NPC添加（推荐）

1. **找到NPC脚本目录**  
   通常在：`Mir200\Envir\` 或项目对应的脚本目录。

2. **创建或编辑NPC**  
   - 新建NPC：在 `cfg_npclist.xls` 中配置NPC，脚本名填 `AutoPickup`（或你自定义的名称）。  
   - 或把 `AutoPickup_NPC.txt` 的内容合并到已有NPC脚本中。

3. **放置脚本文件**  
   - 将 `AutoPickup_NPC.txt` 复制到脚本目录。  
   - 若引擎按文件名加载，可重命名为 `AutoPickup.txt` 或你NPC配置里填写的脚本名。

4. **测试**  
   进入游戏，与NPC对话，点击「开启自动拾取」即可。

### 方式二：登录时自动开启

1. **找到登录脚本**  
   一般为 `QManage.txt` 中的 `[@Login]` 段。

2. **添加命令**  
   在 `[@Login]` 的 `#Act` 段中加入：
   ```
   PICKUPITEMS 0 8 500
   ```

3. **可选：加条件**  
   在 `#If` 段加条件，例如仅对VIP或某等级以上玩家开启：
   ```
   #If
   check [100] 1
   #Act
   PICKUPITEMS 0 8 500
   ```

### 方式三：按钮/界面触发

在按钮脚本的 `#Act` 段中直接写：

```
#Act
PICKUPITEMS 0 8 500
```

## 四、参数调整建议

| 场景 | 参数2（范围） | 参数3（间隔） |
|------|----------------|----------------|
| 普通挂机 | 6~8 | 500~800 |
| 高密度刷怪 | 8 | 500 |
| 低负载/省资源 | 4~6 | 800~1000 |

---

## 五、常见问题

**Q: 拾取没反应？**  
- 确认是64位引擎时，参数2最大为8；32位最大为6。  
- 检查背包是否已满。

**Q: 如何只拾取部分物品？**  
- 使用 `LINKPICKUPITEM` 在 `QFunction-0.txt` 中写过滤逻辑。  
- 参考 `QFunction_PickupFilter.txt` 示例。

**Q: 如何关闭自动拾取？**  
- 执行：`PICKUPITEMS 0 0 0`
