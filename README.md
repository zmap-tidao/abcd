# 论坛QQ群发帖通知

Discuz! X3.5 论坛与QQ群对接插件，实现发帖自动通知到QQ群。

## 功能

- 设置QQ群WebHook后，论坛发帖可自动推送到群
- 支持选择**部分板块**或**全部板块**发帖时通知
- 可分别开关**新主题**和**回复**两种通知类型

## 插件位置

完整插件位于 `discuz_qqgroup_notify/` 目录，安装时将该目录上传到 Discuz 的 `source/plugin/` 下。

详见 [discuz_qqgroup_notify/README.md](discuz_qqgroup_notify/README.md)
